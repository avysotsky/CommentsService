# Security review — 1.1.0.14 / Проверка безопасности / Перевірка безпеки

## English

Scope: comment create/read/preview, CAPTCHA, image/TXT processing and delivery, SPA rendering, request limits and response headers. This is a source review with automated local tests, not an independent penetration test or dependency vulnerability scan.

The review confirmed three gaps in 1.1.0.13: missing browser security headers, preview bodies above 1 MiB being accepted, and duplicate/case-variant JSON properties being accepted. Version 1.1.0.14 adds API SecurityHeaders and the shared JsonRequest boundary. JSON uses UTF-8, exact camelCase names, no duplicates/unknown fields, maximum depth16 and a 1MiB actual-byte bound. Both declared-size and chunked requests are checked. Invalid input returns400, unsupported media/charset415 and oversized JSON413. Multipart remains bounded at6MiB overall, with image5MiB and TXT100KiB limits; invalid individual files return400.

All application responses carry nosniff, X-Frame-Options DENY, no-referrer and camera/microphone/geolocation restrictions. CSP denies sources by default; scripts, styles and API connections are same-origin. Images additionally allow data/blob for CAPTCHA and the viewer. Inline/evaluated scripts, embedded objects, base URL overrides and framing are disallowed. TXT downloads retain `default-src 'none'; sandbox`, attachment disposition and generated UUID filenames. All API responses are no-store; Kestrel does not publish a Server header. Local HTTP remains available; TLS/HSTS and public edge rate limits belong to deployment.

Existing controls retained: strict XHTML allowlist (`a`, `i`, `strong`, `code`), safe HTTP(S) links, disabled DTD resolution, bounded XML complexity, React element allowlisting/literal fallback, parameterized EF queries and typed sort selection. Image codec/decode checks, pixel/byte limits, orientation/resizing/re-encoding and metadata removal remain enforced. TXT remains strict UTF-8 with bounded bytes and no binary controls; downloads preserve exact original bytes. One optional image OR TXT is saved atomically with its owning comment. Client metadata is server-derived and omitted from public DTOs. CAPTCHA is expiring, bounded and single-use; it is not user authentication. Comments and submitted e-mail are public by design. No cookie session or CORS permission was added.

Evidence: 268 backend tests (27 Domain,84 Application,56 Infrastructure/database,101 HTTP),26 frontend tests, frontend/Docker builds, real Kestrel known-length/chunked/overall-body checks, Edge desktop/360px and18 retained-million paging scenarios passed. Browser tests exercised real CAPTCHA, unsafe XHTML/XXE rejection, replay, rejected SVG/invalid UTF-8, safe SQL-like text, hostile read-only DTO rendering, exact TXT downloads and normal image/preview behavior without CSP violations. Test-injected inline script and framing were blocked. Negative writes used owned fixtures in the persistent test database; cleanup removed only those fixtures. Full row fingerprints/schema/history of all three databases, corpus metadata, volumes, checkpoint hashes, private environment and existing preview identity/state matched before/after.

Upgrade from1.1.0.13: rebuild/restart the app with the same environment, Compose overrides and volumes. No schema/dependency changes; migration20261030130243_TextAttachments remains current. Existing callers must send canonical camelCase UTF-8 JSON within1MiB. Preserve databases and restore-verified checkpoints. External hosting/TLS, edge abuse protection, independent penetration testing, dependency vulnerability scanning and manual screen-reader/VS/Workbench checks were not performed in this iteration. They must not be inferred from the passing local checks.

## Русский

Объём: создание/чтение/предпросмотр комментариев, CAPTCHA, обработка/выдача изображений и TXT, вывод SPA, лимиты запросов и заголовки. Это проверка исходников и автоматические локальные тесты, не независимый пентест или сканирование уязвимостей зависимостей.

Подтверждены три пробела1.1.0.13: отсутствие защитных заголовков браузера, принятие предпросмотром тел более1МиБ и повторных/отличающихся регистром JSON-полей. Версия1.1.0.14 добавляет SecurityHeaders и общий JsonRequest в API. JSON требует UTF-8, точные camelCase-поля без дубликатов/неизвестных имён, вложенность до16 и фактический объём до1МиБ. Проверяются объявленная длина и chunked. Неверный ввод даёт400, MIME/кодировка415, большой JSON413. Multipart ограничен6МиБ суммарно, изображение5МиБ, TXT100КиБ; неверный отдельный файл даёт400.

Все ответы приложения имеют nosniff, X-Frame-Options DENY, no-referrer и ограничения камеры/микрофона/геолокации. CSP по умолчанию запрещает источники; скрипты, стили и API доступны с собственного origin. Для CAPTCHA/просмотра изображения дополнительно разрешают data/blob. Inline/eval-скрипты, встроенные объекты, подмена базового URL и фреймы запрещены. TXT сохраняет `default-src 'none'; sandbox`, attachment и UUID-имя. Все ответы API имеют no-store; Kestrel не публикует Server. Локальный HTTP сохранён; TLS/HSTS и публичные лимиты на границе сети относятся к развёртыванию.

Прежние меры сохранены: строгий список XHTML (`a`, `i`, `strong`, `code`), безопасные HTTP(S)-ссылки, запрет DTD, ограничения сложности XML, разрешённые React-элементы/текстовый fallback, параметризованные EF-запросы и типизированная сортировка. Проверяются кодек/декодирование изображения, пиксели/байты, ориентация/уменьшение/перекодирование и удаление метаданных. TXT остаётся строгим UTF-8 с лимитом байтов и запретом двоичных управляющих символов; скачивание сохраняет исходные байты. Одна картинка ИЛИ TXT сохраняется атомарно с комментарием. Метаданные клиента определяет сервер и не включает в публичный DTO. CAPTCHA ограничена по сроку/количеству и одноразовая, но не является аутентификацией. Комментарии и введённый e-mail публичны по назначению приложения. Cookie-сессии и CORS-разрешения не добавлялись.

Подтверждения: прошли268 backend-тестов (27 Domain,84 Application,56 Infrastructure/БД,101 HTTP),26 frontend, сборки frontend/Docker, реальные Kestrel-проверки известной длины/chunked/общего тела, Edge desktop/360px и18 сценариев сохранённого миллиона. Браузер проверил настоящую CAPTCHA, отказ XHTML/XXE, повтор кода, отказ SVG/неверного UTF-8, SQL-подобный текст, безопасный вывод вредоносного DTO без записи, точные TXT и нормальные изображения/предпросмотр без нарушений CSP. Внедрённый тестом inline-скрипт и фрейм заблокированы. Негативные записи использовали собственные фикстуры постоянной тестовой БД; удалены только они. Совпали полные отпечатки строк/схемы/истории трёх БД, метаданные набора, тома, хеши копий, приватное окружение и ID/состояние прежнего просмотра.

Обновление с1.1.0.13: пересоберите/перезапустите приложение с прежним окружением, Compose overrides и томами. Схема/зависимости не менялись; текущая миграция20261030130243_TextAttachments. Клиенты должны отправлять точный camelCase UTF-8 JSON до1МиБ. Сохраните БД и проверенные восстановлением копии. Внешний хостинг/TLS, защита от злоупотреблений на сетевой границе, независимый пентест, сканирование зависимостей и ручные проверки экранным диктором/VS/Workbench на этом этапе не выполнялись. Успешные локальные проверки не подтверждают эти пункты.

## Українська

Обсяг: створення/читання/попередній перегляд коментарів, CAPTCHA, обробка/видача зображень і TXT, виведення SPA, межі запитів і заголовки. Це перевірка джерел та автоматичні локальні тести, не незалежний пентест або сканування вразливостей залежностей.

Підтверджено три прогалини1.1.0.13: відсутність захисних заголовків браузера, прийняття переглядом тіл понад1МіБ та повторних/відмінних регістром JSON-полів. Версія1.1.0.14 додає SecurityHeaders і спільний JsonRequest у API. JSON потребує UTF-8, точних camelCase-полів без дублікатів/невідомих назв, вкладеності до16 та фактичного обсягу до1МіБ. Перевіряються оголошена довжина й chunked. Хибний ввід дає400, MIME/кодування415, великий JSON413. Multipart обмежено6МіБ загалом, зображення5МіБ, TXT100КіБ; хибний окремий файл дає400.

Усі відповіді застосунку мають nosniff, X-Frame-Options DENY, no-referrer та обмеження камери/мікрофона/геолокації. CSP типово забороняє джерела; скрипти, стилі та API доступні з власного origin. Для CAPTCHA/перегляду зображення додатково дозволяють data/blob. Inline/eval-скрипти, вбудовані об’єкти, підміна базового URL і фрейми заборонені. TXT зберігає `default-src 'none'; sandbox`, attachment і UUID-назву. Усі відповіді API мають no-store; Kestrel не публікує Server. Локальний HTTP збережено; TLS/HSTS і публічні межі на краю мережі належать до розгортання.

Попередні заходи збережено: суворий список XHTML (`a`, `i`, `strong`, `code`), безпечні HTTP(S)-посилання, заборона DTD, межі складності XML, дозволені React-елементи/текстовий fallback, параметризовані EF-запити й типізоване сортування. Перевіряються кодек/декодування зображення, пікселі/байти, орієнтація/зменшення/перекодування та видалення метаданих. TXT залишається суворим UTF-8 із межею байтів і забороною двійкових керівних символів; завантаження зберігає початкові байти. Одне зображення АБО TXT зберігається атомарно з коментарем. Метадані клієнта визначає сервер і не включає в публічний DTO. CAPTCHA обмежена строком/кількістю й одноразова, але не є автентифікацією. Коментарі та введений e-mail публічні за призначенням застосунку. Cookie-сесії та CORS-дозволи не додавали.

Підтвердження: пройшли268 backend-тестів (27 Domain,84 Application,56 Infrastructure/БД,101 HTTP),26 frontend, збирання frontend/Docker, реальні Kestrel-перевірки відомої довжини/chunked/загального тіла, Edge desktop/360px та18 сценаріїв збереженого мільйона. Браузер перевірив справжню CAPTCHA, відмову XHTML/XXE, повтор коду, відмову SVG/хибного UTF-8, SQL-подібний текст, безпечне виведення шкідливого DTO без запису, точні TXT й нормальні зображення/перегляд без порушень CSP. Впроваджений тестом inline-скрипт і фрейм заблоковано. Негативні записи використовували власні фікстури постійної тестової БД; видалено лише їх. Збіглися повні відбитки рядків/схеми/історії трьох БД, метадані набору, томи, хеші копій, приватне оточення та ID/стан попереднього перегляду.

Оновлення з1.1.0.13: перебудуйте/перезапустіть застосунок із попереднім оточенням, Compose overrides і томами. Схема/залежності не змінювалися; поточна міграція20261030130243_TextAttachments. Клієнти мають надсилати точний camelCase UTF-8 JSON до1МіБ. Збережіть БД та перевірені відновленням копії. Зовнішній хостинг/TLS, захист від зловживань на краю мережі, незалежний пентест, сканування залежностей і ручні перевірки екранним диктором/VS/Workbench на цьому етапі не виконувалися. Успішні локальні перевірки не підтверджують ці пункти.
